🎨 Dessin Majd

Dessin Majd est une petite application web de dessin créée comme projet d’apprentissage.

L’objectif est de découvrir tout le processus de création et de publication d’une application web avant de travailler sur des projets plus importants.

✨ Fonctionnalités

* 🖌️ Dessiner avec un pinceau
* ◇ Utiliser une gomme
* 🎨 Choisir une couleur
* 📏 Modifier la taille du pinceau
* 🗑️ Effacer complètement la toile
* 💾 Télécharger son dessin en PNG
* 📱 Utiliser l’application sur tablette et ordinateur

🎯 Objectif du projet

Ce projet sert principalement à apprendre :

1. Organiser les fichiers d’une application web.
2. Créer une interface avec HTML et CSS.
3. Ajouter des fonctionnalités avec JavaScript.
4. Tester une application dans un navigateur.
5. Préparer une application pour sa publication en ligne.
